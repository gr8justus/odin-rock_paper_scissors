# Rock Paper Scissors

This project entails writing the logic for the rock paper scissors game, which is played entirely in the browser console.

## Features

- **Interactive Gameplay:** Play against a computer opponent directly from your browser console.
- **Randomized AI:** The computer generates a random, unbiased choice every round.
- **Instant Validation:** The game immediately determines the winner based on classic rule logic.
- **Score Tracking:** Keeps a running tally of player wins, computer wins, and ties.

## Rules of the Game

- **Rock** beats Scissors (crushes them).
- **Paper** beats Rock (covers it).
- **Scissors** beats Paper (cuts it).
- Identical choices result in a **Tie**.
